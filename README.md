# HiKeep — ناحیه کاربری

رابط کاربری فارسی و راست‌چین مبتنی بر Next.js App Router، React، TypeScript و Tailwind CSS.

## اجرا
1. Node.js نسخه 20 یا جدیدتر نصب باشد.
2. `npm install`
3. `npm run dev`
4. مرورگر: `http://localhost:3000`

## نکات مهم
- پالت رنگ در `src/app/globals.css` مطابق مقادیر خواسته‌شده تعریف شده است.
- فونت IRANSans در `public/fonts/` قرار می‌گیرد. فایل فونت در این بسته ارائه نشده؛ فایل‌های مجاز و دارای مجوز خودتان را با نام‌های `IRANSansX-Regular.woff2` و `IRANSansX-Bold.woff2` در آن مسیر قرار دهید. تا آن زمان فونت جایگزین سیستم استفاده می‌شود.
- تم در مرورگر ذخیره می‌شود و اسکریپت اولیه از نمایش نادرست تم تا حد امکان جلوگیری می‌کند.
- اطلاعات حساب، پیام‌ها و تیکت‌ها نمونه هستند و در این نسخه به API وصل نیستند.
- ورود و خروج واقعی، ذخیره سمت سرور، مجوزها و امنیت نشست نیازمند پیاده‌سازی بک‌اند است؛ فرم ورود فعلی نمایشی است و نشست واقعی ایجاد نمی‌کند.
- قوانین رسمی و اطلاعات شرکت تا زمان دریافت محتوای معتبر، با پیام «محتوا هنوز ارائه نشده است» نشان داده می‌شوند.
